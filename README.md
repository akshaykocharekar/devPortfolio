# Persona Craft

Hi! I want you to build a modern, premium-quality personal portfolio website.

I'll share the following files with you:

Resume – My professional experience, education, projects, and achievements.

design.md – My preferred design direction, colors, layout ideas, and visual inspiration.

skill.md – My technical skills, tools, and technologies.

Please analyze all of these files carefully before starting.

Tech Stack

React.js

Tailwind CSS

Vite (preferred)

Fully responsive (mobile, tablet, and desktop)

Design Requirements

I want the portfolio to feel:

Modern and elegant

Clean and minimal

Premium and polished

Smooth and interactive

Fast-loading and optimized

Visually impressive without being cluttered

The design should have excellent typography, spacing, subtle animations, and a cohesive color palette. Every section should feel intentional and professionally crafted.

Sections

Build the portfolio based on the information in my resume and include:

Hero section

About Me

Skills

Experience

Projects

Education

Achievements (if applicable)

Certifications (if available)

Contact section

Footer

Only include sections that have relevant information in my resume.

Animations

Use tasteful animations throughout the site:

Smooth page transitions

Fade and slide-in effects

Hover interactions

Scroll-triggered animations

Micro-interactions for buttons and cards

Animations should enhance the experience, not distract from it.

Projects

Create attractive project cards that include:

Project image or placeholder

Live demo link (if available)

Skills

Display skills in a visually engaging way, such as:

Categorized skill cards

UI/UX Expectations

Pixel-perfect layout

Consistent spacing

Excellent responsiveness

Accessible color contrast

Semantic HTML

Reusable React components

Well-organized folder structure

Clean, maintainable code

Performance

Optimize for Lighthouse scores.

Lazy-load images where appropriate.

Keep animations smooth (60 FPS).

Minimize unnecessary re-renders.

Deliverables

A production-ready React + Tailwind CSS portfolio.

Modular and reusable components.

Clean project structure.

Easy to customize in the future.

Comments where necessary for maintainability.

The final result should look like a premium developer portfolio that stands out and feels unique, rather than a generic template. Focus on exceptional user experience, beautiful visual hierarchy, smooth interactions, and professional aesthetics while staying true to the information provided in my resume and supporting files.
